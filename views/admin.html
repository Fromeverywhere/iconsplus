🚀 快速起步

  1. 首次部署后用默认账号登录：admin / iconsplus（登录后立即在「用户管理」改密码）。
  2. 在「用户管理」给家人/朋友建账号：管理员用 超级管理员；只帮忙提交图标的用 上传+调用；只取用图标的用 仅调用。
  3. 往 images/ 下建文件夹（文件夹名就是分类），把图标文件丢进去即可，前台自动出现。
  4. 想用中文分类名？去「分类管理」改显示名，文件夹名保持英文更稳。

🗂️ 分类管理（超级管理员）

  • 改显示名：只改前台展示的文字，不影响外链，随时可改。
  • 重命名文件夹：会移动磁盘目录和缩略图，外链 URL 从此变成 /images/<新文件夹名>/<文件>，旧链接立即 404。已在 Docker/导航站里引用过的，改完要同步更新。
  • 管理图片：点「管理图片」可查看该分类下所有图标并删除。删除不可恢复，操作前想清楚。
  • 文件夹名规则：中文、字母、数字、中划线、下划线；不能以点开头，不能重名。
  • 也可以不走后台：直接在宿主机 images/ 目录里增删文件夹和文件，服务会自动识别（缩略图会自动对账）。

📥 提交与审核

  • 前台「提交图标」或后台「我的提交」：填站点名称、站点网址、图标接口（返回 JSON 的 URL）。
  • 接口格式：{ "category": "可选分类", "icons": [ { "name": "xx", "url": "https://…/x.png" } ] }
  • 超级管理员在「审核队列」点「通过」→ 后台自动拉取图标入库（异步，可关页面）。拒绝可填原因。
  • 同一站点/接口在待审、导入中、已通过状态下不可重复提交。

🔗 外链与 API

  • 图标直链（映射红线，永不改变）：/images/<分类文件夹名>/<文件名>
  • 列表接口（公开）：/api/icons.json，返回 [{ name: 文件夹名, label: 显示名, icons: [...] }]
  • 缩略图加速：/thumbs/… 自动生成 webp，缺失自动回退原图；前端无需关心。
  • 程序化提交：带 Authorization: Bearer <Token> 调 POST /api/submissions，Token 在「API 调用」页签。
  • 如果你在外部引用了 /api/icons.json 做导航站数据源：新增了 label 字段用于展示，name 字段含义不变，旧代码兼容。

🛡️ 防盗链

  • 「防盗链设置」里开启后按 Referer 校验：白名单按 host 后缀匹配（填 example.com 则其子域也放行）。
  • 黑名单优先级更高；「允许空 Referer」建议开着，否则浏览器直接打开图片链接会被拒。

⚠️ 注意事项

  • 图片目录 images/ 通常挂载在宿主机（如飞牛 /vol1/1000/Docker/images），容器升级重建不会丢图；但 data/（账号、提交记录、分类显示名）也请一并挂载持久化。
  • 改 Docker 镜像版本不影响图片与数据；升级前备份这两个目录更稳妥。
  • 删除图片/重命名文件夹都没有二次恢复机制，重要图库请定期备份 images/。

删除操作不可恢复，请谨慎确认。
